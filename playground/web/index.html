Decis playground

Three games that play themselves by asking a real decision model. Every move is a POST /v1/systemone call; the playground serves the pages and forwards those calls to the running engine with the API key attached, so the browser never holds one.

●Snake

A 12×12 grid with a flood-fill safety analysis. The model picks between four moves from the safe-move set; the probability bars show what it weighed.

▲Dino

The Chromium offline runner, with a physics planner that marks jump, duck and run safe, unsafe or best. The model chooses; an optional shield vetoes.

▦Tetris

Each turn the page enumerates the placements of the current piece and asks which to play, plus a strategy, a stack-health score and a boolean.

The engine is discovered The playground probes /readyz and connects to whichever engine answers.
