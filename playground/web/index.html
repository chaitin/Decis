Decis playground

Three games that ask a real decision model for every move, and that you can also play yourself from the keyboard. Each move is a POST /v1/systemone call; the playground serves the pages and forwards those calls to the running engine with the API key attached, so the browser never holds one. All three pages use the same shell: one manual/AI switch, one inference panel, one console for the last call.

●Snake

A 12×12 grid with a flood-fill safety analysis. In AI mode the model picks between four moves from the safe-move set; the arrow keys play it by hand. Either way the probability bars show what the model weighed.

choice · 4 options

▲Dino

The Chromium offline runner, with a physics planner that marks jump, duck and run safe, unsafe or best. Space and the arrow keys play it by hand; in AI mode the model chooses, with an optional safety net that refuses a move the planner calls unsafe.

choice · 3 options

▦Tetris

Each turn the page enumerates the placements of the current piece and asks which to play, plus a strategy, a stack-health score and a boolean. The arrow keys and space play it by hand; in AI mode the model plays the shortlist it was given.
