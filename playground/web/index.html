Decis playground

Three games that play themselves by asking a real decision model. Every move is a POST /v1/systemone call; this page and the games are served by the playground, which forwards those calls to the running engine and attaches the API key, so the browser never holds one.

A 12×12 grid with a flood-fill safety analysis. The model picks between four moves from the safe-move set; the probability bars show what it weighed.
